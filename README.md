# 🐠 夢幻水族箱

低多邊形風格的休閒養魚網頁遊戲，手機橫向玩最舒服。

**開始玩：** https://hn84786349.github.io/aquarium/

## 玩法
- 點水族箱投放飼料，魚吃飽會長大；兩隻同種的成魚會生小魚
- 魚會產出寶物，點一下或滑過去就能撿起來換成金幣
- 50 種魚、10 種造景、17 種背景，放生魚可以換星星兌換 21 種夢幻生物
- 關掉遊戲後魚兒也會幫忙賺金幣（離線收益）

## 在手機上全螢幕玩
- **iPhone：** 用 Safari 打開網址 →「分享」→「加入主畫面」，之後從主畫面圖示打開
- **Android：** 用 Chrome 打開網址 → 右上角「⋮」→「加到主畫面」或「安裝應用程式」

## 換網址或換手機
在「選單 → 設定」按「📤 匯出存檔」複製存檔碼，到新的地方按「📥 匯入存檔」貼上即可。

## 程式檔案
遊戲程式依功能拆成多個檔案，`index.html` 會照順序載入（順序不能換，後面的檔案會用到前面的東西）：

| 檔案 | 內容 |
|---|---|
| `index.html` | 畫面結構（按鈕、選單的框架） |
| `css/style.css` | 所有樣式 |
| `js/core.js` | 基本常數與小工具 |
| `js/scene.js` | 造景：資料與繪製 |
| `js/state.js` | 遊戲狀態、存檔、畫布與背景 |
| `js/fish-base.js` | 魚的繪製工具（身體、魚鰭、花紋） |
| `js/fish-models.js` | 每一種魚的外觀設定 |
| `js/fish-draw.js` | 特殊造型的魚與夢幻生物繪製 |
| `js/data.js` | 遊戲資料：寶物、魚種、夢幻魚、飼料、背景 |
| `js/update.js` | 每一幀的更新：魚、繁殖、寶物、蝸牛 |
| `js/render.js` | 每一幀的繪製、星星背景、戳泡泡小遊戲 |
| `js/input.js` | 點擊與操作 |
| `js/cloud.js` | 存檔保護、雲端存檔、匯出匯入 |
| `js/ui.js` | 選單與各分頁畫面 |
| `js/features.js` | 圖鑑、成就、每日任務、拍照、改名、訪客、節日 |
| `js/loop.js` | 主迴圈與離線收益 |
| `js/music.js` | 背景音樂 |
| `js/main.js` | 遊戲啟動 |

更新檔案時，記得把 `index.html` 裡每個檔案後面的 `?v=` 版本號一起改掉，手機才不會用到舊的快取。

拆檔前的單一檔案版本保留在 `backup-before-split` 分支。
