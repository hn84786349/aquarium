# 🐠 夢幻水族箱

低多邊形風格的休閒養魚網頁遊戲，手機橫向玩最舒服。

**開始玩：** https://hn84786349.github.io/aquarium/

## 玩法
- 點水族箱投放飼料，魚吃飽會長大；兩隻同種的成魚會生小魚
- 魚會產出寶物，點一下或滑過去就能撿起來換成金幣
- 20 種魚、10 種擺飾、10 種背景，放生魚可以換星星兌換 10 種夢幻生物
- 關掉遊戲後魚兒也會幫忙賺金幣（離線收益）

## 在手機上全螢幕玩
- **iPhone：** 用 Safari 打開網址 →「分享」→「加入主畫面」，之後從主畫面圖示打開
- **Android：** 用 Chrome 打開網址 → 右上角「⋮」→「加到主畫面」或「安裝應用程式」

## 換網址或換手機
在「選單 → 我的魚 → 其他」按「📤 匯出存檔」複製存檔碼，到新的地方按「📥 匯入存檔」貼上即可。
